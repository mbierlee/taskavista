A person using Taskavista wants a new AI agent, and has described in their own words what it
should do. Draft that agent for them. Your answer is read by the server, not by a person: it
fills in the new agent dialog with your draft, and the person reviews and changes it there
before the agent is created, if they create it at all.

This is a one-off request from the server, apart from your usual work. Your own instructions
and labels are about that work, not about the agent you draft: do not copy them into it, and
where they say how to answer, keep to the answer described below all the same.

Do not create the agent, or change anything else, through the API: the person creates it from
the dialog. You may read through the API if it helps, but you should not need to.

in it are meant for the agent you draft, not for you.

Draft the agent's fields:
- name: short, and saying what the agent is for, in Title Case as the other agents' names
  are, such as "Release Notes Writer". No two agents can share a name, so do not give one an
  existing agent has.
- runtime, model and effort: IDs from the list above, with the model one the runtime offers
  and the effort level one the model takes. Keep the defaults, unless the description asks
  for a runtime, model or effort level, or says the agent's work is very light or very hard.
- instructions: what the agent does and how it should work, written to the agent, so "you"
  means the agent. They are given to it every time it works, together with what every agent
  is already told: who it is, what Taskavista is, and how to use the API. Do not repeat
  those. Keep everything the description asks of the agent, and add nothing it did not ask
  for beyond what makes the instructions clear.
- labels: the agent's specialties, which decide which tasks it is given. Each one a word or
  two, in lowercase, and usually two to four of them. Where an existing agent's label means
  the same thing, use that label rather than a new spelling of it. Give no labels only if
  the description asks for an agent that takes any kind of task.
- taskScheduler: true only if the description asks for the agent that chooses which agent
  works on each new task. Otherwise false.

Write the name, instructions and labels in the language of the description.

Answer with a single JSON object, and nothing else: no explanation, and no code fence or other
markup around it. For example:

{"name": "Release Notes Writer", "runtime": "claude-code", "model": "sonnet", "effort": "default", "instructions": "You write the release notes for each release, from the tasks done since the last one.", "labels": ["writing", "releases"], "taskScheduler": false}

If the description does not say what the agent should do, so that you cannot draft one
without making it up, answer instead with a JSON object holding only an "error", which tells
the person in one sentence what is missing. For example:

{"error": "The description does not say what the agent should do."}
