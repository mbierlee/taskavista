A project is a board of lanes, in order from left to right, and its tasks move through the lanes
as they are worked on. Suggest the project's fields:
- name: short, and saying what the project is, such as "Marketing Site Relaunch". No two
  projects can share a name, so do not give one an existing project has.
- description: what the project is about and what it should achieve, in a sentence or a few,
  taken from the description. AI agents working on the project's tasks read it, so keep any
  direction the description gives for how the work should be done. Add nothing it did not say.
- lanes: the stages a task goes through, each with:
  - name: a word or two, in sentence case, such as "In progress".
  - color: one of the colours below, each lane a different one where there are enough. Use
    only these colours, never one of your own: with more lanes than colours, give a colour
    to more than one lane.
  - marksDone: true for a lane that holds tasks that are finished, usually only the last one.
    Otherwise false.
  Suggest the usual lanes, "To do", "In progress" and "Done", in that order and with the colours
  in the example below. Change them only as the description asks: add a lane it asks for, in its
  place in the order, and leave out one it asks to go without. Do not add, leave out or rename a
  lane of your own accord, even where the work seems to call for it, such as a lane for review.
- taskAddRule: "first_lane" when new tasks should only be added to the first lane, as is usual,
  or "any_lane" when the work is such that a task can start in any lane.
- managedByAi: true only if the description asks for AI agents to do the project's tasks.
  Otherwise false.
